# Installation

Run PolyHUB-0.2.1-setup.exe. Setup installs for your Windows account without administrator rights. Choose a dedicated empty folder and desktop/Start menu shortcut options. The default is %LOCALAPPDATA%/Programs/PolyHUB.

Reinstall or upgrade with the same or a newer official setup while PolyHUB is closed. The registered directory and shortcut choices are preserved. Setup rejects downgrades and does not adopt arbitrary portable folders.

Uninstall from Windows installed apps or Uninstall.exe. Only PolyHUB-owned program files, shortcuts and registration are removed. Other Poly apps, documents and local preferences remain. PolyHUB registers no document file associations.

Portable: extract the whole PolyHUB folder from the win-x64 ZIP. A portable PolyHUB can manage registered Poly applications but its own in-place updater requires conventional installation.

Settings and operation records are in %LOCALAPPDATA%/PolyHUB. Update storage is in its Updates subfolder. Keep backups after an interrupted update until you have confirmed a working installation.
